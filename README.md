## 简体中文

### 项目简介

TutuToken 是一个以可爱兔子为形象的 Meme 代币，基于 Linea 区块链。所有 Linea 的 LXP 持有者都可以领取 Tutu 代币。此合约已经成功部署在 Linea 主网，前端由 [Tutu-Web-App](https://github.com/foreverdesmond/Tutu-Web-App) 提供。

### 合约地址

- **Linea 主网**: `0x81957f4ac4fae880b164740d39208a22afd7a398`
- 浏览器: https://explorer.linea.build/address/0x81957f4ac4fae880b164740d39208a22afd7a398

### 代币信息

- **代币名称**: Tutu
- **代币符号**: TUTU
- **LXP 合约地址**: 由部署者指定
- **开发者钱包地址**: 由部署者指定

### 主要功能

- **claim | 领取代币** — 用户可通过支付额外的 0.0001 ETH 的 gas 费用来领取 TUTU 代币
- **getClaimableAmount | 查询可领取余额** — 查询用户可领取的 TUTU 代币数量
- **withdrawDeveloperBalance | 开发者提取 Gas 费** — 开发者可以提取累积的 gas 费用

### 技术栈

- **Solidity** — ERC-20 代币合约
- **Linea** — 部署网络（Chain ID: 59144）

### 部署

合约已部署在 Linea 主网，用户可通过合约地址进行交互。

## English

### Project Overview

TutuToken is a cute rabbit-themed meme token based on Linea. All Linea LXP holders can claim Tutu tokens. This contract has been successfully deployed on the Linea mainnet, and the frontend is provided by [Tutu-Web-App](https://github.com/foreverdesmond/Tutu-Web-App).

### Contract Address

- **Linea Mainnet**: `0x81957f4ac4fae880b164740d39208a22afd7a398`
- Explorer: https://explorer.linea.build/address/0x81957f4ac4fae880b164740d39208a22afd7a398

### Token Information

- **Token Name**: Tutu
- **Token Symbol**: TUTU
- **LXP Contract Address**: Specified by deployer
- **Developer Wallet Address**: Specified by deployer

### Main Functions

- **claim** — Users can claim TUTU tokens by paying an additional 0.0001 ETH gas fee
- **getClaimableAmount** — Query the amount of TUTU tokens a user can claim
- **withdrawDeveloperBalance** — Developer can withdraw accumulated gas fees

### Tech Stack

- **Solidity** — ERC-20 token contract
- **Linea** — Deployment network (Chain ID: 59144)

### Deployment

The contract is deployed on the Linea mainnet, and users can interact with it via the contract address.
